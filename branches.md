# Ветки в Git

## Зачем нужны ветки?
Ветки позволяют работать над разными задачами одновременно.

## Основные команды:
- _git branch_ - показать ветки

- _git branch new_ - создать ветку

- _git checkout new_ - переключиться на ветку

- _git merge new_ - объединить ветки


## Пример workflow:
1. Создать ветку для новой функции

2. Работать в этой ветке

3. Объединить с основной веткой

# Команды Git

## Ежедневные команды:
+ _git add_ . - добавить все файлы

+ _git commit -m _"описание" - сохранить изменения

+ _git status_ - проверить статус

+ _git log_ - посмотреть историю


## Работа с файлами:
+ _git add index.html_ - добавить конкретный файл

+ _git rm file.txt_ - удалить файл

+ _git mv old.txt new.txt_ - переименовать файл

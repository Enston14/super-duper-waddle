# Удаленные репозитории

## GitHub и другие хостинги
Позволяют хранить код в интернете и работать в команде.

## Основные команды:
+ _git clone URL_ - скопировать репозиторий

+ -git push_ - отправить изменения
 
+ _git pull_ - загрузить изменения

+ _git remote -v_ - показать удаленные репозитории


## Типичный workflow:
1. `git pull` - получить свежие изменения

2. работать над кодом

3. `git push` - отправить свои изменения

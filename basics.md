# Основы Git

## Что такое Git?
Git сохраняет историю изменений в вашем проекте.

## Базовые понятия:
- **Репозиторий** - папка с проектом под контролем Git
- **Коммит** - сохранение изменений
- **Ветка** - отдельная линия разработки

## Первые команды:
+ _git init_ - создать репозиторий

+ _git status_ - проверить состояние

+ _git add_ - добавить файлы
